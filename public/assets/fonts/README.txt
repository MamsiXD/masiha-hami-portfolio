Place your local Yekan Bakh font files in this folder (`public/assets/fonts/`):

Recommended filenames (WOFF2 for best speed & compression, or TTF fallback):
- YekanBakh-Light.woff2   (weight 300)
- YekanBakh-Regular.woff2 (weight 400)
- YekanBakh-Medium.woff2  (weight 500)
- YekanBakh-SemiBold.woff2 (weight 600)
- YekanBakh-Bold.woff2    (weight 700)

If you have .ttf files instead of .woff2, name them:
- YekanBakh-Light.ttf
- YekanBakh-Regular.ttf
- YekanBakh-Medium.ttf
- YekanBakh-SemiBold.ttf
- YekanBakh-Bold.ttf

If you only have a single variable font file, name it:
- YekanBakh-VF.woff2 (or YekanBakh-Regular.woff2 / .ttf)

The CSS `@font-face` rules in `src/index.css` are already pre-configured for these files!
